# Rice leaf dataset

Store labeled images in this structure:

```text
rice_leaf/
  train/
    healthy/
    blb/
    rice_blast/
  validation/
    healthy/
    blb/
    rice_blast/
```

Use separate images in `train` and `validation`; do not put the same photo in both. Keep the dataset images out of Git if the collection is large or has licensing restrictions.
